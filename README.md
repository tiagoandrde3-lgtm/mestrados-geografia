# Mestrados Geo — versão minimalista

Portal estático em HTML, CSS, JavaScript e JSON. Não usa framework nem backend.

## Publicar no GitHub Pages
1. Crie um repositório público.
2. Envie todo o conteúdo desta pasta para a raiz do repositório.
3. Em Settings → Pages, selecione Deploy from a branch, branch `main` e pasta `/(root)`.
4. Salve e aguarde a publicação.

## Atualizar dados
Edite `data/programas.json`. O layout e as páginas usam esse arquivo como fonte de dados.

## Observação
Os dados incluídos são uma base inicial. Antes de publicar informações como vagas, taxas, datas e exigências, confira cada item no edital oficial correspondente.
